# CV privado de Javier Maestre

Repositorio privado para conservar y editar el CV web.

## Archivos

- `index.html`: estructura y contenido del CV.
- `styles.css`: diseño visual y adaptación móvil.
- `app.js`: selector Español/Inglés.

## Vista local

Descargar o clonar el repositorio y abrir `index.html` en el navegador.

## Privacidad

- No habilitar GitHub Pages si se desea conservar el CV privado.
- El HTML contiene `noindex`, `nofollow` y `noarchive`.
- Antes de publicar, revisar email, LinkedIn y cualquier otro dato personal.
